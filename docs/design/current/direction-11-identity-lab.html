Identity lab Type Signature Neutrals

Four decisions stand between Direction 11 and an ownable identity: the wordmark device, the signature, the typeface, and the neutral temperature. Each is switchable above and every section below re-renders live — judge combinations, not swatches. Two proposed system behaviours (the data voice, the dot) and the component fixes from the critique follow. Convention exception: this file loads webfonts (the typeface is the thing under test); offline it degrades to system stacks.

01 · The wordmark deviceThe colon is Wellfound’s — the last borrowed piece. Candidates below are devices, not logos: each must survive the topbar at 19px, a browser tab at 16px, and mean something.

Tradeoffs
Period. The dot is drawn (a circle, not a glyph), sized to the wordmark, in accent. Reads as a decision: a real answer, period — the product’s one promise. Scales to a 3px favicon dot. Risk: lowercase-name-with-period is a known startup register; the drawn dot and the dot-system below (05, 07) are what keep it ours.
Middot. Names the two sides (zot · hub) with the same separator the UI already uses for meta text — the system’s own punctuation promoted to the mark. Risks: reads as hyphenation, invites “zot-dot-hub” pronunciation, and the device disappears at 16px.
Bare. Quietest, nothing to defend — but nothing to recognize either, and the favicon loses its device.
Why a dot at all
Direction 11 already speaks in dots: status badges carry one, “actively recruiting” pulses one, live counts sit behind one. The wordmark dot makes that latent system official — the dot carries the state — and gives favicon, badge, pulse and mark one shared element. No UCI cliché (no anteater, no blue/gold), but quietly native: the dot is the ant.
Recommendation: the period. It is the only candidate that is simultaneously a device (survives 16px), a meaning (the answer, delivered), and a system (the same dot the UI already uses for state). The middot is cleverer than it is legible; bare is safe but forgettable.

03 · TypefaceThe foundation locked “display face + workhorse text face” and v2 shipped one system stack — unresolved. Three stacks, each tested where type actually breaks: 12.5px tables and form labels.

Character
System. The current stand-in. Free, instant, and platform-dependent: SF Pro’s tight display reads “Apple keynote” on a Mac and turns into Segoe UI on the Windows laptops most officers carry. A brand that changes voice per OS is not yet a brand.
Instrument Sans (+ Serif for the signature). One superfamily, two voices, designed together. Slightly narrow, warm, geometric-humanist; the only option where the serif-italic signature is native rather than imported. ~55KB total, self-hostable.
Schibsted Grotesk display + Inter text. The literal “display + workhorse” model. Schibsted has real personality at 56px (angled terminals, tight apertures); Inter is the safest dense-UI face alive — and already in production, so migration is display-only. Most conventional of the three.

Cool — the current spine
Greys derived from ink #071417. Precise, technical, closest to Wellfound’s own translucent greys. Against the pink accent washes it runs slightly clinical — the “wants to open it in a park” half of the brief gets no help from the surfaces.
Paper — the foundation’s spec
Warm ivory page (#F9F7F3), white cards, warm ink #141109. Cards separate from the page tonally — which is the grouping fix from the studio, strengthened. Crimson reads warmer against it. Risk: drifts toward Direction 09’s territory and can read “stationery” if the washes pile up. All ramp pairs re-measured AA in both themes.
Recommendation: Paper. It delivers what the foundation already promised, gives card-grouping tonal support, and is the single cheapest move away from “generic ATS” — one variable set, no layout change. Keep ink-derived cool only if we amend the foundation doc to say so deliberately.

What this settles
Events stop impersonating roles. A role is a countdown (deadline in the meta line); an event is a date (the mono chip). Different time semantics now look different — structure decision §1, delivered with typography instead of a second hue.
The secondary colour question closes. With the chip carrying “event-ness,” the teal/blue slot has no remaining job. Recommendation: no secondary colour. If events ever need more, the chip can take the accent — not a new hue.

06 · Component fixes from the critiqueThree measured failures, each with its systemic fix — not a patch. Plus the one shape question worth asking before the system is derived.

W1 · The panel gets its own accent aliases
For clubs — old: accent on panel, 3.80:1 ✗ For clubs — new: panel-accent, 5.9:1 ✓
Recruit without the spreadsheet.
The dark card is a dark context in both themes, so it carries theme-independent tokens: --panel-accent / --panel-accent-text (the dark theme’s accent pair). Rule: every surface owns a full alias set; nothing inherits accent across a register boundary.
W2 · Inputs get a compliant boundary
A third line weight (--line-3, per-ramp values in the tokens) exists only for control boundaries — inputs, checkboxes, selects — and holds 3:1 on every surface inputs sit on, in all four ramps. Hairlines stay decorative; boundaries carry 3:1. Focus stays accent.
W3 · The 375px rule, actually applied

Below 480px the primary keeps 44px and the secondary demotes to ghost/overflow — the studio’s own rule, now expressed as a component variant instead of a footnote. No 34px targets on touch.
Shape — pills vs. set squares
Pills (current) read friendly and are Wellfound’s shape; 10px squares read more instrument-like and match the input radius. Tradeoff: pills + drawn-dot wordmark keep the round family consistent; squares differentiate harder from the source material. Lean: keep pills — the dot system is round, and shape-switching buys less than type + neutrals already did.

07 · Motion — the dot carries the stateTokens: 150 / 200 / 250ms on one ease. One signature: when state changes, the dot pulses once. Never loops, never decorative. Click the buttons.

New
Accept → badge swaps to Accepted and its dot pulses once (600ms, then still). Undo restores. The pulse is the confirmation — no toast needed for the common case.
Rules
--t-fast 150ms hover, press, focus · --t-base 200ms reveal, swap, fade-up · --t-slow 250ms panels, sheets. One ease: cubic-bezier(.2,.7,.3,1).
The dot pulses once on state change — application submitted, decision made, posting went live. It never loops (the old 30s-polling spinner anxiety is the anti-pattern), and it dies under prefers-reduced-motion.
Earned moments only: first posting published and application submitted may compose dot-pulse + fade-up. Everything else uses the plain tokens.

08 · The recommended bundleSet the switches to: Instrument · Serif · Paper. That combination is the candidate identity.

zothub ● (drawn period, accent) · Instrument Sans everywhere with Instrument Serif italic as the signature voice · paper neutrals, crimson unchanged · mono data voice with the event date chip and no secondary colour · accent = demands action · the dot pulses once on state change. Pills stay. Every failure from the critique (W1–W3) is fixed systemically above.
What this buys over v2: platform-independent voice, a device that is ours at every size from 3px to 56px, warmth the foundation promised, event/role distinction without new colour, and a motion signature that is also a status system. What it costs: one webfont family (~55KB, self-hosted), and letting go of the SF-Pro-tuned tracking table.
