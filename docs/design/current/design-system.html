The tokens, marks, and parts everything else is built from.

Derived from direction-11-v4-uci.html — the locked visual identity. This is the source of truth: change a value here and every screen inherits it. Brand marks

One gesture — upright ink tipping into italic accent — carries the headline signature, the wordmark, and the icon.

Wordmark — inline (topbar, docs, running text)

Construction: Instrument Sans 700, zot in --ink, hub in italic --accent-text (light) / --accent (dark). Tracking −0.045em. Always one line; never stack the inline wordmark.

Stacked mark — avatar, app icon, favicon, social

Don’t — never a lone “z”; never put the inline wordmark inside a disc; never re-colour zot.
Production note: these are font-rendered lockups. For shipped assets (favicon .ico/.png set, social), outline the glyphs from the licensed Instrument Sans — a mechanical step once the font is licensed. Disc fill #101112, letters #F5F5F6 / italic #5AA2E6.

Instrument Sans, one superfamily. The italic is load-bearing — it is the signature and the wordmark. Numbers the system knows speak mono.

Tracking scales with size: −0.034em display, −0.026em section, −0.018em card, near-0 at body. Tight tracking on big type, relaxed on small.
Two jobs for italic: the accent signature (one phrase per view) and the wordmark’s hub. Never italicise body copy for emphasis — use weight.

08

Operating rules

The non-negotiables every screen inherits. From the strategy foundation, carried into tokens.
Never a dead end

Every state offers the next action. No message names a problem without a remedy; no empty result ends the journey. When principles conflict, this wins.

Honest about state

Live counts only — data describing the product’s state, never copy describing its stage. No fabricated stats, ever.

Accent = demands action

Blue marks the thing to act on now, and primary CTAs. Status colours stay reserved for status. Colour is never the sole carrier of meaning.

Density follows the task

Cards ↔ list ↔ table is first-class on any collection. Same components at both densities — a compact variant, never a different component.

AA is a merge gate

Every pair contrast-verified by measurement (1.4.3 text and 1.4.11 boundaries). Visible focus everywhere. 44×44 touch targets. Every icon-only control labelled.

Not UCI-official

Campus-adjacent, not impersonating: the blue and the photo say “built for UCI,” never a seal, gold, or endorsement. Identity lives in tokens, so a rebrand is a token swap.
